# Personal Portfolio Website:
=============================

A responsive and modern personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This project showcases your skills, experience, projects, and contact information in a clean and professional layout.

## 🚀 Features:
=================================================

- Responsive design for all devices
- Animated navigation menu
- Smooth scrolling between sections
- Project showcase with images and links
- About and contact sections
- Downloadable resume (optional)
- Interactive UI using vanilla JavaScript

## 🛠️ Tech Stack:
====================================================

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6)
